# Calculadora Interativa em Python

## Sobre o projeto

Programa desenvolvido em Python que permite realizar diferentes operações matemáticas a partir de um menu interativo.

O usuário informa dois números e pode escolher entre somar, multiplicar, comparar os valores ou inserir novos números.

## Funcionalidades

- Soma entre dois números.
- Multiplicação entre dois números.
- Comparação para identificar o maior número.
- Identificação de números iguais.
- Atualização dos valores durante a execução.
- Menu interativo com opção para encerrar o programa.
- Tratamento de opções inválidas.

## Conceitos de Python utilizados

- Variáveis e tipos numéricos.
- Entrada de dados (`input`).
- Estrutura de repetição (`while`).
- Estruturas condicionais (`if`, `elif` e `else`).
- Operadores aritméticos e relacionais.
- Formatação de strings com `format()`.
- Controle de fluxo do programa.

## Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Execute o arquivo Python pelo terminal ou por uma IDE, como PyCharm.

## Exemplo de utilização

**Entrada:**
```text
Primeiro valor: 10
Segundo valor: 5
```

**Operações disponíveis:**
```text
[ 1 ] Somar
[ 2 ] Multiplicar
[ 3 ] Maior
[ 4 ] Novos números
[ 5 ] Sair
```

**Exemplo de resultado:**
```text
A soma entre 10 e 5 vale 15
```

## Objetivo

Praticar estruturas condicionais, estruturas de repetição e construção de menus interativos utilizando Python.
